# Protein-Glycan Docking Benchmarks

This directory contains benchmarking scenarios for protein-glycan docking using HADDOCK3. Glycans are carbohydrate chains attached to proteins and lipids, and they play critical roles in cell signalling, immune recognition, and pathogen-host interactions.

These benchmarks use true interface (TI) restraints derived from the glycan structure to guide docking (meaning by that that the interface residues are used to define ambiguous interaction restraints, i.e. no specific contacts), and evaluate multiple clustering strategies to identify the best-performing protocol for protein-glycan complexes. 

## Dataset

- **Input lists**: generated by running `setup.sh`
  - `protein-glycan-input.txt`: all complexes (bound scenario)
  - `protein-glycan-input-unbound.txt`: the 55 complexes with an unbound receptor and a glycan ensemble (`unbound_true_interface_act-pass-cltsel`)
  - `protein-glycan-input-flexdock.txt`: the same 55 complexes, with the receptor ensemble `_r_u_ensemble` (`unbound_true_interface_flexdock_act-pass-cltsel`)
- **Molecule suffixes**: `_r_b` (receptor, bound), `_l_b` (glycan, bound), `_r_u` (receptor, unbound), `_l_u` (glycan, unbound), `_l_ensemble` (glycan conformational ensemble, used by the unbound scenarios), `_r_u_ensemble` (unbound receptor repeated as many times as the glycan ensemble has models, made by `setup.sh` for the flexdock scenario, which pairs receptor and glycan models one to one)
- **Restraint files**: `_ti-aa.tbl` (true interface on both protein and glycan), `_tip-ap.tbl` (true interface on protein, glycan fully passive)
- **Reference structure**: `_analysis.pdb` — used for CAPRI evaluation

## About Ambiguous Interaction Restraints

Ambiguous Interaction Restraints (AIRs) guide docking by defining potential contacts between the protein and glycan. The benchmark includes two AIR schemes:

- **`ti-aa`**: true interface residues are defined on both the protein and glycan.
- **`tip-ap`**: true interface residues are defined on the protein, while the glycan is treated as fully passive.

## Scenarios

As we are dealing with glycans, as recommended in the protein-glycan docking protocol paper (see below), the weight of the intermolecular van der Waals energy is increased to 1 for the scoring at the rigidbody stage (w_vdw=1) and only flexible refinement is performed (i.e. no emref step).

### bound_true_interface_act-pass-cltsel

The simplest scenario: both the protein receptor and the glycan ligand are provided in their bound (co-crystal) conformations. TI restraints derived from the reference complexes are used to drive the docking. A clustering step is added after rigid-body docking to select models from the top50 clusters for the flexible refinement.

### unbound_true_interface_act-pass-cltsel

Same protocol as for `bound_true_interface_act-pass-cltsel`, but starting from the unbound receptor structure and an ensemble of unbound conformations for the glycan (see reference paper below). As we are dealing with an ensemble of conformation, the sampling at the rigidbody step is increased to 4000.

### unbound_true_interface_flexdock_act-pass-cltsel

This is a special docking scenario, in which the docking takes place during the flexible refinement stage (i.e. no rigidbody docking step). To this end the length of the protocol is increased (mdsteps statements in the yaml file), the glycan is treated as fully flexible with a sampling factor of 25 for each of the 20 receptor-glycan model pairs (500 models per target).
